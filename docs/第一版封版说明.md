# 第一版封版说明（v1.0.6.4）

> 封版日期：2026-11-12　｜　版本：`1.0.6.4`（唯一来源 `VERSION`）
> 用途：这一版把"模型生成 / 动作库 / 视频动补"三条产线做齐，并把它们的契约、命令、测试固定下来。

## 1. 这一版有什么

| 能力 | 入口 | 状态 |
|---|---|---|
| A 模型生成动作 | `pipelines/unimate/scripts/unimate-pipeline.sh` → `unimate-loop.sh` | 可用，已实测 |
| B 动作库接入 | `unimate-import-clip.sh` / `unimate-import-batch.sh` | 可用，已接入 10 条库动作 |
| 两版交付（循环版 + 完整版） | `unimate-pack.sh` | 可用 |
| **D 视频动补** | `Motion2MixamoRig/tools/motion2mixamo_command.py` | 可用,punch.mp4 全片实测 |
| 契约与索引 | `core/action_schema.py` / `action_meta.py` / `action_index.py` | 唯一出处,三种来源统一 |
| 自动化测试 | `tests/smoke.sh`(UniMate 侧 59 项)、`tests/smoke.py`(动补侧 79 项)、`tests/slow.py` | 全绿 |

## 2. 实测数字（可复现的基线）

**动补(punch.mp4,1832×920 / 60fps / 75.3s → 2259 帧 @30fps)**

| 指标 | v2 启发式焦距 | v3 距离反推焦距 |
|---|---|---|
| 焦距 | ~2050 px(对角线启发式) | **1481 px**(像素身高 762 × 3.4m ÷ 1.75m) |
| 世界位移 | 0.62 m | **0.50 m** |
| 脚锁修正(均/最大) | 2.94 / 16.77 cm | **2.38 / 13.39 cm** |
| 自穿插 | 77 帧 / 最深 5.53 cm | 88 帧 / 最深 5.39 cm |
| 落地修正 | 957 帧陷地 → 0 | 937 帧陷地 → 0 |

**性能**:落地测量向量化后 2259 帧 11.9s → 4.3s(2.7×),与参考实现逐帧偏差 0.00000 mm。

## 3. 这一版**不做**什么（明确的边界）

| 未做/未验 | 影响 | 何时做 |
|---|---|---|
| 真实双机位 L0/L2 | `fuse_camera_views.py` 只有合成数据验证 | 拿到双机位素材后 |
| 手指全链(GVHMR + HaMeR + MANO) | `--detect-hands` 未端到端验 | 需要手指细节时 |
| 多人/合影素材 | 动补按"面积最大的人"取,不区分 | 需要时加显式多人检测 |
| 输出帧率 | 固定 30 fps(源 60 会被降采样) | 暂无计划 |
| `punch.mp4` 的真实焦距 | 素材是屏幕录制,无镜头参数;3.4m 是估算 | 你给真实值再出 v4 |

## 5. 复现步骤(换机器从零跑)

```powershell
# 1. 依赖:引用库 Motion2MixamoRig(只读) + 它的 .venv(torch cu128 / gvhmr)
Copy-Item AIGenAnimPrj\Motion2MixamoRig\config.example.env AIGenAnimPrj\Motion2MixamoRig\config.env
#    填 MOTION2MIXAMO_HOME / MOTION2MIXAMO_PYTHON / BLENDER_EXECUTABLE(ffmpeg 走 PATH 也行)

# 2. 自检
Motion2MixamoRig\.venv\Scripts\python.exe Motion2MixamoRig\tools\motion2mixamo_config.py

# 3. 测试(两条产线各一套)
bash tests/smoke.sh
Motion2MixamoRig\.venv\Scripts\python.exe tests\smoke.py

# 4. 跑一条动补
Motion2MixamoRig\.venv\Scripts\python.exe Motion2MixamoRig\tools\motion2mixamo_command.py run `
  --video assets\video\punch.mp4 --rig assets\mixamo\X_Bot.fbx --device cuda `
  --distance 3.4 --person-height 1.75 --output-dir outputs\video_cap\cap_punch_v4
```

## 6. 封版后怎么改

- 遵循 `AGENTS.md` §10:提交前先 `git status`、只 add 自己的文件、不用 `-A`。
