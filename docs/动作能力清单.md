# UniMate 能做到哪些动作（实测 + 数据统计）

> 数据来源：UniML3D 的 ```export/*/motion_captions.json```，共 **13,769 条**带文本的动作片段
> （mixamo 2,317 / truebones 1,097 / objaverse 10,355）。
> 统计脚本：```tools/caption_stats.py```，可随时重跑。

## 1. 一句话结论

模型只会做**训练分布内**的动作。分布内的稳，分布边缘的要靠多采，
**分布外的换办法**——而"分布外"有两种：数据里没有，和数据里有但表示不出来。

## 3. 怎么判断一个动作能不能做

| 该动作在 caption 里的占比 | 判断 | 做法 |
|---|---|---|
| **> 5%** | 在分布中心 | 直接用，调 prompt 与 ```--cfg_scale``` |
| **1% ~ 5%** | 学到了但样本少 | ```--reps 6``` 以上，用 ```gait_report``` / ```roll_check``` / 循环报告挑最好的一条 |
| **< 1%** | 边缘，容易失败 | 同上报复性多采；同时准备第 4 节的替代方案 |
| **查不到** | 没学过 | 直接走第 4 节，别在 prompt 上耗 |

自查命令：

`````````bash
hf download Linzhan/UniML3D --repo-type dataset --local-dir tmp/meta \
    --include "export/*/motion_captions.json" --include "export/*/category_groups.json"

python tools/caption_stats.py --meta tmp/meta                    # 全表
python tools/caption_stats.py --meta tmp/meta --grep roll        # 查某个动作
`````````

## 4. 模型做不到的时候怎么办

### 4.1 先分清是哪一种"做不到"

| 类型 | 例子 | 判别方法 |
|---|---|---|
| **A 数据里没有** | 攀岩、开车、双人摔跤 | ```caption_stats --grep``` 查不到 |
| **B 数据里有但表示不出来** | 前滚翻、后空翻、侧翻 | 查得到 caption，但生成结果里根骨累计转角远不到 360° |
| **C 数据里有但太稀有** | 手势示意、爬行 | 占比 < 1% |
| **D 需要交互/物理** | 抓取贴合、脚踩实地、推箱子 | 有地面接触、物体接触约束 |

### 4.2 B 类的根因（已经查清）

翻滚在训练数据里**有 191 条**（```Dive_Roll```、```Prone_Roll```、```Quick_Roll_To_Run```、
```Front_Flip```、```Cartwheel```…），但模型做不出来。原因在特征提取：

`````````
# data_process/utils/skeleton.py: get_root_facing_quat
across  = joints[r_hip] - joints[l_hip]      # 左右轴，来自关节位置
forward = Y_up × across                      # 前向
返回把 forward 转到 Z+ 的四元数
`````````

根节点的"朝向"是从**关节位置的水平投影**算出来的，所以它天生只含**偏航**。
躯干俯仰/侧倾在这条通道里被投影掉了，而根骨自己的旋转又被朝向四元数顶替
（```motion_utils.py: cont_6d_params_reordered[:, 0] = root_facing_quat```）。

实测印证：所有生成动作里根骨相对首帧的最大偏转 **26°**，主轴**永远**竖直。

**结论：整圈翻转在这个表示下不可表达，换 prompt / 调 cfg / 多采样都无效。**

### 4.3 处理办法

| 类型 | 推荐做法 | 我们已有的工具 |
|---|---|---|
| C 稀有 | 多采 + 指标挑 | ```gait_report.py```、```roll_check.py```、```make_loop.py``` 的报告 |
| B 表示不了 | **混合**：模型出姿态 + 程序补运动 | ```add_root_spin.py```（补一圈旋转）、```flatten_root.py```（根位移） |
| A 数据没有 | **外部动作库**：同骨架直接驱动，不用重定向 | ```simplify_rig.py```（Mixamo 65→22）、```inspect_rig.py``` |
| A 数据没有（找不到现成） | 手工关键帧 / 动捕 | 导出的 FBX 与手工动画同格式，可直接混用 |
| D 物理/交互 | 引擎侧 IK + 物理，或脚部 IK 修正 | 本工程不做，属于引擎职责 |
| 长期要覆盖 | 微调训练（需 UniML3D + 多卡） | 上游仓库支持，本工程不涉及 |

**对翻滚这件事，最省事的其实是"外部库"**：Mixamo 动作库里就有
```Dive_Roll``` / ```Prone_Roll``` / ```Quick_Roll_To_Run```（训练数据里那些 caption 就是从它来的）。
下载 → ```unimate-inspect.sh``` 看关节数 → ```unimate-simplify.sh --mode mixamo``` → 直接驱动同一套骨架。

## 5. 能不能靠继续训练补上？

结论：**分两种情况，别混。**

### 5.1 加 Mixamo 数据没用（它已经在训练集里）

UniML3D 里的 mixamo 部分就是 2,317 条 Mixamo 片段，
`unimate_mixamo_f60_v2` 这个权重正是用它训出来的。
再往里加 Mixamo 动作，不会新增任何类别。

### 5.2 表示层限制，加多少数据都学不会

翻滚在训练集里有 **191 条**，还是做不出来，原因在特征表示（第 4.2 节）：
根朝向由关节位置的水平投影算出，只含偏航；根骨自身旋转又被朝向四元数顶替。
**这一类问题无法通过继续训练解决**，必须改特征。

要真支持整圈翻转，得做四件事：

1. fork UniMate，把根朝向从"偏航朝向"改成"完整四元数"（或额外开一路 pitch/roll 通道）；
2. 用新特征重抽全部 13,769 条片段的特征（要能跑数据处理管线，Blender 逐资产导出）；
3. 从头训练（官方配置：batch 16/卡、120k~150k 步、74M 参数；单卡 5090 上量级是数天，需实测）；
4. canonical bake / animate / 采样入口都要同步改。

这是"改表示 + 重训"的项目，不是微调。**只在"任意翻转是核心产品能力"时才值得做。**

### 5.3 训练真正划算的地方：稀有但可表示

| 类别 | 占比 | 值不值得微调 |
|---|---|---|
| 手势示意 | 0.7% | 值得：手势是通用需求，且完全可表示 |
| 爬行攀爬 | 0.3% | 看需求 |
| 进食嗅闻 | 0.04% | 只有动物向才需要 |

做法：把这些片段的量级补到几千条，用现有权重微调（不涉及改表示）。
成本主要是**数据**，不是算力。

### 5.4 优先级建议

| 顺序 | 手段 | 适用 | 成本 |
|---|---|---|---|
| 1 | **动作库 + 重定向** | 库里有的动作（翻滚、攀爬、受击） | 已跑通，一条命令 |
| 2 | **模型 + 程序补** | 刚体/机械（车轮、滚筒）、或基础片段四肢动作已很足；**有四肢的动作不行**（实测四肢只动 7%） | 已有工具 |
| 3 | **微调训练** | 稀有但可表示（手势、爬行） | 需要补数据 + 数天算力 |
| 4 | **改表示 + 重训** | 表示层限制（任意翻转/翻滚） | 数周，需 fork |

### 5.5 实测教训：只看"转了多少"会误判

第一次验证"模型 + 程序补一圈"时，我只量了根骨累计转角（366°），判定"成功"。
实际观感是**躺着被转了一圈**，身体没有翻滚的姿态。

补量了"四肢相对根骨坐标系的动作幅度"才看清差别：

| 版本 | 根骨累计转角 | 四肢动作幅度 | 观感 |
|---|---|---|---|
| 动作库（Sprinting Forward Roll） | 484° | **49.9%** | 正常就地翻滚 |
| 模型姿态 + 程序补一圈 | 366° | **7.4%** | 整体转了一圈，姿势没动 |

现在这条检查固化在 `tools/verify_anim.py`：整体翻转和四肢动作**分开量**，
两个都够才算合格。

## 6. 已知的其它边界

| 边界 | 说明 |
|---|---|
| 单片段 60 帧 / 2 秒 | 更长要用 ```--motion_expand``` 串接 |
| 原地动作 | 位移交给引擎（```flatten_root.py``` 负责拉平） |
| 关节 5~71 | 超过要走 Truebones 权重（≤85）或精简 |
| 无脚部 IK | 脚底会滑，需要在引擎里补 |
| 无物体交互 | 抓取、推拉只是"手在动"，不解决接触 |
| 只吃英文 prompt | 训练 caption 是英文，中文要先翻 |
| 固定 fps 30 | 与训练一致 |
