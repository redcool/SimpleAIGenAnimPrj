# 动物动作交付（7 个 Unity Store 模型）

> 产线：`unimate-pipeline.sh`（生成）→ `unimate-loop.sh`（循环化 + 打包）。
> 每个模型 idle / walk / run 各 3 次采样，按步态指标挑最好的一条。
> 来源：**全部为模型生成**（`source: model`），仅鸡一例回退到自带动画。

|---|---|---|---|---|

| **Pinguin_001** | 20 | 0.039 | ⚠️ 相位不典型（3 条里 1 条腿动得明显） | 看视频定 |

判定标准：`gait_report.py` 量四条腿竖直摆幅 + 两两相位相关。
成型步态 = 对角同相 + 左右反相（小跑），或前后各自同相且左右高度同相（袭步）。

## 每个包的结构（两版）

@F@@F@@F@
outputs/actions/<模型>_pack/
├── <模型>_character.fbx     角色本体（Generic Rig）
├── anim/                    ★ 循环处理版（直接用）
│   ├── idle.fbx
│   ├── walk.fbx
│   └── run.fbx
├── full/                    ★ 完整序列（未做循环处理，供人工另切）
│   ├── idle_full.fbx         原地版（默认用这个）
│   ├── walk_full.fbx
│   ├── run_full.fbx
│   ├── idle_full_motion.fbx  带根位移的原版（看得到"在往前走"）
│   ├── walk_full_motion.fbx
│   ├── run_full_motion.fbx
│   └── cycle_candidates.txt  候选循环点（帧号 + 脚差）
└── action.json              来源、挑中哪条、两种版本说明
@F@@F@@F@

**用法**：
1. 先用 `anim/` 里的循环版；
2. 循环不对时，打开 `full/` 的完整序列，按 `cycle_candidates.txt` 给的帧号找区间，
   例如"起点 44 结束 80"，人工确认后自行切。

**完整序列的长度**：Tiger / Horse 的 walk、run 是 **160 帧**（3 段串接，含 2~3 个周期），
其余模型与 idle 是 60 帧（生成器单次输出就是 60 帧）。
160 帧的意义：60 帧常常连一个完整周期都放不下，人工也很难在里面找到"两帧相同"。

### 完整序列也做了原地化

完整序列默认给**原地版**（`*_full.fbx`），带位移的原版留作对照（`*_full_motion.fbx`）。
实测根节点首尾水平位移（单位≈角色身高量级）：

| 模型 | 动作 | 带位移 | 原地版 |
|---|---|---|---|
| Tiger | run | 0.779 | **0.034** |
| Tiger | walk | 0.152 | **0.007** |
| Horse | walk | 0.096 | **0.014** |
| Horse | run | 0.031 | 0.020 |
| Dog | run | 0.262 | **0.005** |
| Dog | walk | 0.214 | **0.001** |

做原地化用 `tools/flatten_root.py`：按帧减掉一条线性漂移，只动位移不动旋转。
残留的 0.01~0.03 是"线性拉直"和真实曲线的差，肉眼看不出来。

### 候选循环点清单长什么样

@F@@F@@F@
=== Tiger_001-an_object_runs_forward-rep_0-0.npy   160 帧   脚: ['后右', '后左', '前右', '前左']
    起点   7  结束  26  长度  19 帧   脚差 0.08（2.56 倍步长）
    起点 116  结束 156  长度  40 帧   脚差 0.08（2.70 倍步长）
    起点 117  结束 158  长度  41 帧   脚差 0.08（2.71 倍步长）
@F@@F@@F@

- "脚差"是四只脚位置差的均值（归一化到脚的行程），越小越像
- "倍步长"是同一差值除以正常一步的距离，>1.5 说明接缝处脚会跳
- 想自己重新生成清单：`python pipelines/unimate/tools/cycle_candidates.py --samples <目录> --top 12`

## 循环点怎么定的（v1.0.4.3 改）

按**脚的轨迹**找，而不是按全身姿态：

1. 用关节名认出四肢末端（腿脚优先，鸟才退到翅膀）；
2. 在整段里搜"起点 + 周期"，代价 = 四只脚的位置差（含下一帧的速度项）；
3. 判"像不像"用**脚的行程比例**（默认 12%），尺度无关，大小动物同一套阈值；
4. 达标候选里再挑"末帧到首帧那一步最接近正常步长"的一条；
5. 脚几乎不动（待机）时不切周期，整段保留。

报告字段 `foot_seam_ratio`：接缝处脚差了几倍正常步长。≤1.1 能用，>1.4 会看出停顿。

改造前后（77 条动作）：

| 指标 | 按旋转（旧） | 按脚（新） |
|---|---|---|
| 找到真实周期 | 1 条 | **21 条** |
| 接缝 ≤1.1 | 1 条 | **12 条** |
| Dog 跑步 | 整段收拢（停顿） | **接缝 0.52**（真循环） |

## 没有循环段时怎么办（Tiger / Horse 实测）

两条路，都不用手 K：

| 办法 | 做法 | Tiger 实测 | Horse 实测 |
|---|---|---|---|
| **多采几条** | 同一 prompt 采 8 条，按接缝挑 | 只有 8 帧假周期 | 17 帧周期，接缝 1.7 |
| **加长时长** | `motion_expand` 串 3 段 → **160 帧**（原 60 帧） | 找到 21 / 41 帧周期，接缝 0.72 | 找到 17 / 37 帧周期，接缝 0.46 |

结论：**加长有效**。60 帧里往往连一个完整周期都放不下，串到 160 帧后周期和接缝都能落地。
命令：

```bash
cd UniMate
OUTPUT_DIR=<工程>/outputs/samples/Tiger_001_long \
ASSETS=<工程>/outputs/rig/Tiger_001 \
PROMPT="An object runs forward.|An object runs forward.|An object runs forward." \
COND_PATH=<工程>/outputs/rig/Tiger_001/cond.npy \
EXPAND_OVERLAP=10 REPLICATE=4 \
bash pipelines/unimate/scripts/run_sample_motion_expand.sh <工程>/models/unimate_uniml3d_f60_v3
```

之后照常 `unimate-loop.sh --samples <...>/motion_expand`。

⚠️ 一个待你目视确认的点：加长路线选出的周期偏短（Tiger 21 帧 / Horse 17 帧，约 0.6~0.7 秒一轮），
脚部接缝很好（0.72 / 0.46），但按全身旋转算的接缝指标不同意（判定写着"不适合循环"）。
两种度量打架时，建议在 Unity 里看实际播放 —— 步态看脚更准，姿态漂移看旋转更准。

## 怎么挑的

- **idle**：待机幅度本来就该很小（0.001~0.005），按循环接缝挑
- **walk / run**：成型步态优先，否则挑腿部幅度最大的那条
- 挑选结果写在每个包的 `action.json` 的 `qa.picks` 里，可以回溯到底用了哪条 npy

## 已知问题

| 问题 | 说明 | 处理 |
|---|---|---|
| 鸡的腿不动 | 6 条 walk/run 腿部幅度 0.002~0.006，翅膀倒是在动 | 用 `builtin/` 里自带的动画（同一套骨架，直接用） |
| 前腿叫 "Front Thigh" | 这批模型的自动标签是机器人式命名（Front/Back 前缀） | Dog/Tiger 已能出成型步态，暂不改；个别动物步态别扭时再手工改成手臂链 |
| 相位"不典型" | 腿在动但不成标准步态 | 多采几次（`--reps 6`）挑，或直接用自带动画对比 |

## 复现

`````````bash
bash pipelines/unimate/scripts/unimate-pipeline.sh \
    --input "Arts/models/Dog_001.fbx" --name Dog_001 \
    --exp-dir models/unimate_uniml3d_f60_v3 --reps 3 \
    --prompt "An object stands still." \
    --prompt "An object walks forward." \
    --prompt "An object runs forward." \
    --out outputs/samples/Dog_001

bash pipelines/unimate/scripts/unimate-loop.sh --samples outputs/samples/Dog_001 --name Dog_001 \
    --rig outputs/rig/Dog_001/Dog_001.glb \
    --out outputs/actions/gen_Dog_001_locomotion

python pipelines/unimate/tools/gait_report.py --samples outputs/actions/gen_Dog_001_locomotion
`````````
