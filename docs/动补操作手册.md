# 动补操作手册(Motion2MixamoRig 产线)

> 版本:v1.0.5.9。对应代码 `AIGenAnimPrj/Motion2MixamoRig/`。
> 与 UniMate 侧的 [操作手册](操作手册.md) 平行:那份讲"模型生成/库接入",这份讲"视频动补"。

## 0. 一句话

**一段真人视频 → Mixamo 骨架角色动画(GLB + FBX),带落地修正与穿模报告。**
交付落 `outputs/video_cap/<cap_*>/ `;引用库 `../Motion2MixamoRig`(仓库外)只读。

## 2. 配置(一次配好)

复制模板 → 填本机路径:

```powershell
Copy-Item AIGenAnimPrj\Motion2MixamoRig\config.example.env AIGenAnimPrj\Motion2MixamoRig\config.env
```

| 键 | 含义 | 缺省 |
|---|---|---|
| `MOTION2MIXAMO_HOME` | 引用库根目录 | 环境变量 > config.env > 从当前目录向上找(认 `motion2mixamorig/`) |
| `MOTION2MIXAMO_PYTHON` | 跑引用库的解释器 | `<HOME>/.venv/Scripts/python.exe` |
| `MOTION2MIXAMO_ASSETS_VIDEO` | 素材目录 | `assets/video` |
| `MOTION2MIXAMO_DEFAULT_RIG` | 默认角色 FBX | `assets/mixamo/X_Bot.fbx` |
| `MOTION2MIXAMO_OUTPUT_ROOT` | 交付根 | `AIGenAnimPrj/outputs/video_cap` |
| `MOTION2MIXAMO_FOCAL_PIXELS` | 相机焦距(像素) | 空 |
| `MOTION2MIXAMO_DISTANCE_METRES` | 人到相机距离(米) | 空 |
| `MOTION2MIXAMO_PERSON_HEIGHT_METRES` | 画面里人的真实身高(米) | `1.70` |
| `BLENDER_EXECUTABLE` | Blender | `blender`(走 PATH) |

自检(打印当前解析到的全部路径):

```powershell

```

## 3. 尺度怎么给(最重要的一步)

GVHMR 的**绝对深度由焦距决定**;不给就按 ~43mm 等效估 —— 手机主摄(26mm)位移会虚高约 65%。
**朝向和姿势形状不受影响**,所以原地动作看起来一直很准。

三选一,优先级从高到低:

| 方式 | 命令 | 说明 |
|---|---|---|
| 焦距 | `--focal-pixels 1387` | 最直接。手机主摄 26mm @1920 宽 ≈ 1387 |
| 距离 | `--distance 3.4 --person-height 1.75` | 先用 YOLO 量像素身高 s,再算 `f_px = s × 距离 ÷ 真人身高` |
| 都不给 | — | 上游启发式,只适合"只要动作、不管位移" |

换算关系(针孔):
```
像素身高 = f_px × 真人身高 / 距离      →      f_px = 像素身高 × 距离 / 真人身高
```

实测对照(punch.mp4,75.3s):

| | 启发式 ~2050px | 距离 3.4m → 1481px |
|---|---|---|
| 世界位移 | 0.62 m | **0.50 m** |
| 脚锁最大修正 | 16.77 cm | **13.39 cm** |
| 骨盆高度 | 0.921–1.135 m | 0.923–1.137 m(不变) |

## 4. 命令配方(直接抄)

以下都在 `AIGenAnimPrj` 目录下执行;先设解释器变量:

```powershell
$vpy = 'H:\aiworks\motionPrj\Motion2MixamoRig\.venv\Scripts\python.exe'
$t   = 'H:\aiworks\motionPrj\AIGenAnimPrj\Motion2MixamoRig\tools'
```

### 4.1 单条:视频 → 角色动画

```powershell
& $vpy "$t\motion2mixamo_command.py" run `
  --video 'H:\...\assets\video\punch.mp4' --rig 'assets\mixamo\X_Bot.fbx' `
  --device cuda --distance 3.4 --person-height 1.75 `
  --output-dir 'H:\aiworks\motionPrj\AIGenAnimPrj\outputs\video_cap\cap_punch_v4'
```

常用附加参数:`--no-preview`(只要数据,省 ~14 分钟渲染)、`--skeleton <旧run>\skeleton_motion.npz`(跳过抽取,只换角色)、`--no-foot-lock`。

### 4.2 落地修正(必做)

```powershell
& $vpy "$t\ground_character_on_floor.py" outputs\video_cap\cap_punch_v4
# 可选:--always-ground(每帧贴地)、--report(只报数不改文件)、--out 指定输出
```

### 4.3 导出 FBX(Unity 原生)

```powershell
& 'H:\Program Files\blender-5.2.0-windows-x64\blender.exe' -b --factory-startup `
  --python "$t\blender\export_character_fbx.py" -- `
  outputs\video_cap\cap_punch_v4\mixamo_character_grounded.glb `
  outputs\video_cap\cap_punch_v4\mixamo_character_grounded.fbx 30
```

### 4.4 写动作元数据(契约)

```powershell
& $vpy 'core\action_meta.py' --dir outputs\video_cap\cap_punch_v4 `
  --name cap_punch --source capture --rig X_Bot --origin 'punch.mp4' `
  --not-in-place --capture-run outputs\video_cap\cap_punch_v4
& $vpy 'core\action_index.py'     # 重建索引
```

### 4.5 批量跑 + 质检门禁

```powershell
& $vpy "$t\run_batch_captures.py" --videos 'assets\video' --focal-pixels 1387
# 其它参数:--device cuda|--python <解释器>|--out <交付根>|--skip-existing|--limit N
```

报告落 `outputs/video_cap/_batch_reports/batch_report_<时间>.{md,csv}`,
判定:FAIL = 穿模帧 ≥15% 或 最深 ≥8cm 或 脚锁 ≥30cm;WARN = ≥5% / ≥5cm / ≥15cm。

### 4.6 落地对照渲染(带 z=0 地板)

```powershell
& 'H:\Program Files\blender-5.2.0-windows-x64\blender.exe' -b --factory-startup `
  --python "$t\blender\render_floor_contact_stills.py" -- `
  outputs\video_cap\cap_punch_v4\mixamo_character_grounded.glb `
  outputs\video_cap\cap_punch_v4\ground_check '800,1369' after
```

### 4.7 双机位融合(先做 L0 自比)

```powershell
& $vpy "$t\fuse_camera_views.py" fused.npz cam1\skeleton_motion.npz cam2\skeleton_motion.npz --scale
```

输出 `pose_rms_cm`(去掉根位移后的关节分歧)与 `root_rms_cm`(路径分歧)。
恒等用例偏差 0.00cm;模拟第二机位能还原缩放 0.9237(真值 0.9259)。

### 4.8 版本对比(图 + 视频)

```powershell
& $vpy "$t\plot_trajectory_compare.py"          # 轨迹/髋高对比 PNG
& $vpy "$t\make_comparison_video.py" --left <A.mp4> --right <B.mp4> `
  --left-label 'v2 ...' --right-label 'v3 ...' --out outputs\video_cap\cap_punch_v4\compare.mp4
```

## 5. 参数总表

### motion2mixamo_command.py(入口)

| 参数 | 说明 |
|---|---|
| `run` | 子命令,原样转交 m2mr(其它子命令也可透传) |
| `--video` / `--image` | 素材(互斥) |
| `--rig` | 角色 FBX |
| `--device cpu\|cuda\|mps` | 推理设备,默认 cpu(建议 cuda) |
| `--skeleton` | 复用旧 run 的骨架,跳过抽取 |
| `--distance` | 人到相机距离(米),本入口独有,会被摘掉 |
| `--person-height` | 真人身高(米),默认 1.70 |
| `--focal-pixels` | 焦距(像素),优先级最高 |
| `--no-preview` | 不渲染预览 |
| `--no-foot-lock` | 不钉脚 |
| `--output-dir` | 输出目录 |
| `--detect-hands` `--hand-smooth` | 手指(需 MANO) |

### ground_character_on_floor.py

| 参数 | 说明 |
|---|---|
| `<run目录或glb>` | 位置参数 |
| `--out` | 输出文件名,默认 `*_grounded.glb` |
| `--always-ground` | 每帧都贴地(原地动作适用) |
| `--report` | 只报数,不写文件 |

### run_batch_captures.py

| 参数 | 说明 |
|---|---|
| `--videos` | 素材目录,默认配置里的 assets_video |
| `--rig` | 角色,默认配置 |
| `--device` | 默认 cuda |
| `--python` | 引用库解释器,默认取配置并校验 |
| `--out` | 交付根,默认 `outputs/video_cap` |
| `--report` | 报告目录,默认 `<out>/_batch_reports` |
| `--focal-pixels` | 默认取配置 |
| `--skip-existing` `--min-seconds` `--limit` | 跳过已跑 / 太短的片 / 只跑前 N 条 |

### fuse_camera_views.py

| 参数 | 说明 |
|---|---|
| `output inputs...` | 输出 npz + 两个以上机位 |
| `--scale` | 允许整体缩放拟合 |
| `--smooth N` | 融合后滑动平均窗口 |
| `--no-root` | 只融合姿态,忽略根位移 |

### blender/export_character_fbx.py

`blender -b --factory-startup --python export_character_fbx.py -- <in.glb> <out.fbx> [fps]`
丢掉 Icosphere 骨骼显示球,只导出骨架 + 蒙皮网格,动画从 0 帧开始烘帧。

### blender/render_floor_contact_stills.py

`-- <in.glb> <输出目录> <帧号逗号分隔> [前缀]`,加 z=0 地板,低角度渲染。

## 6. 交付契约

`outputs/video_cap/<cap_*>/action.json`(由 `core/action_meta.py` 写):

| 字段 | 动补取值 |
|---|---|
| `source` | `capture`(契约定义见 `core/action_schema.py`) |
| `origin` | 视频文件名 |
| `qa.check` | `motion_capture` |
| `qa` 关键数 | `frames` / `fps` / `self_intersection_frames` / `self_intersection_share` / `self_intersection_max_cm` / `foot_lock_mean_cm` / `foot_lock_max_cm` / `grounded_variant` |

命名:`cap_<动作>_v<版本>`;重跑不覆盖,新版本号。

## 7. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `body model not found` | 先 import 了 gvhmr 再导出路径 | 入口已处理;自写脚本要 `config.ensure_reference_package_importable()` 先行 |
| 位移比实际大 | 没给焦距/距离 | 加 `--focal-pixels` 或 `--distance` |
| 脚滑/飘 | 人物太小、脚被裁、或焦距错 | 重拍(见 `M2MR_素材拍摄SOP.md`)或补焦距 |
| 穿模多 | 遮挡严重、多人入镜 | 换素材 |
| 找不到引用库 | 配置缺失且当前目录不在库内 | 写 `config.env` 或设 `MOTION2MIXAMO_HOME` |
| 渲染太慢 | 预览占全场 60% 时间 | `--no-preview` |
| 手指不动 | 没开 `--detect-hands` | 开它,并提供 MANO |
