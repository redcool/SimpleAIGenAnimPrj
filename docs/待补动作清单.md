# 待补动作清单（模型做不好的，用动作库补）

> 判断口径见 `docs/动作能力清单.md`：训练分布内（≥1% caption 占比）优先用模型，
> 分布外或分支不行的，从动作库补。
> 动作库推荐以 Mixamo 为主（免费、人形齐全、和我们的 22 关节骨架同源）。

## 1. 优先级总表

| 优先级 | 动作族 | 模型表现 | 建议来源 | Mixamo 关键词 |
|---|---|---|---|---|
| **P0** | 翻滚 / 空翻 / 侧翻 | **做不出**（根朝向只含偏航，表示层限制） | 动作库 | `Roll`、`Dive Roll`、`Forward Roll`、`Backflip`、`Cartwheel` |
| **P0** | 受击 / 击倒 / 死亡 / 起身 | 能出雏形，但受击方向、倒地姿态不准 | 动作库 | `Hit Reaction`、`Knockdown`、`Death`、`Getting Up` |
| **P1** | 攀爬 / 翻越 / 上台阶 | 近乎没有（爬行类 0.3%） | 动作库 | `Climbing`、`Vault`、`Climb Up`、`Ledge` |
| **P1** | 武器：挥砍 / 开枪 / 换弹 / 收拔 | 有 swing/shoot 的 caption，但没有武器约束，手部对不上 | 动作库 | `Sword Slash`、`Rifle Idle`、`Reload`、`Draw` |
| **P2** | 手势：招手 / 指 / 耸肩 / 敬礼 / 点头 | 0.7%，时好时坏 | 优先库（对位准确） | `Wave`、`Point`、`Shrug`、`Salute`、`Head Nod` |
| **P2** | 物体交互：开门 / 按按钮 / 拾取 / 坐下 | 抓放 2.2%，手部位置不保证对上 | 动作库 | `Open Door`、`Push`、`Pick Up`、`Sit Down` |
| **P2** | 爬行 / 匍匐 | 0.3%，容易变形 | 动作库 | `Crawl`、`Prone Crawl` |
| **P3** | 双人交互：握手 / 推搡 / 抓摔 | 数据里几乎没有 | 自录 / 其它库 | — |
| **P3** | 载具：上车 / 驾驶 / 下车 | 几乎没有 | 自录 / 其它库 | `Enter Vehicle`、`Driving` |

## 2. 哪些**不要**用库（模型更好）

| 动作族 | 理由 |
|---|---|
| 走 / 跑 / 待机 / 转身 | 占比 16%/12%/8.5%，模型能出**随机变体**；库是固定片段，容易看出重复 |
| 舞蹈、跳跃、跌倒、蹲起 | 模型分布内，能按 prompt 出不同风格 |
| 动物运动（四足/鸟/鱼/蛇） | 库覆盖差，模型是主力 |
| 需要"每角色略有不同"的循环动作 | 库会千篇一律 |

一句话：**通用动作走模型（要变体），关键动作走库（要对）。**

## 3. 怎么下、怎么接

### 下载

Mixamo 一次可以批量选多个动画导成 FBX（`Skin: Without Skin`，30fps）。
建议按类别建目录：

`````````
Arts/mixamo/
├── rolls/      Sprinting Forward Roll.fbx、Dive Roll.fbx ...
├── hits/       Hit Reaction.fbx、Knockdown.fbx ...
├── climb/      Climbing.fbx ...
└── weapons/    Sword Slash.fbx ...
`````````

### 批量接入

`````````bash
bash scripts/unimate-import-batch.sh \
    --clips Arts/mixamo/rolls \
    --rig outputs/rig/X_Bot --name X_Bot \
    --expect roll --prefix act_
`````````

- `--expect roll`：要求整圈翻转（翻滚类必填），不通过会报错并计入失败
- `--expect motion`：只要求四肢在动（受击、攀爬、手势等用这个）
- 每个片段产出一个目录 `outputs/samples/act_<片段名>/`，带 `action.json`

### 看索引

`````````bash
PYTHONPATH=tools python tools/action_index.py
# -> outputs/actions_index.md / .json
`````````

## 4. 每个动作要满足的交付条件

| 项 | 要求 |
|---|---|
| 动作文件 | FBX（Unity 用）+ GLB（预览用） |
| `action.json` | `source: library`、`origin` 写原始片段名、`loopable`、`in_place` |
| 质量闸门 | `verify_anim.py --expect motion|roll` 通过 |
| 骨架一致 | 与角色同一套 22 关节骨架（`--mode mixamo` 自动处理） |
| 原地 | 库片段多为原地；带位移的要标 `in_place: false` 并在引擎里开 Root Motion |
